This tool issues no dosing recommendation. It integrates a compartmental model across a timeline you define and shows the result. It does not select a dose, rank scenarios, or judge a regimen adequate. The parameters below are illustrative placeholders, not a validated model — replace them with values from a source you can cite before drawing any conclusion. Read the model card before use.

Effect of each CRRT change

Each event is compared against a counterfactual in which that one event did not happen and the previous circuit state simply continued. Dose timing is identical on both sides, so the difference isolates the event rather than confounding it with where the window happens to fall in the dosing cycle. Windows are truncated at the next event. The percentage-of-time metric saturates once a profile sits wholly above or below target, so the unbound AUC change is shown alongside it.

Case file

Four patients. Thirty-six readings. One question: which genes have changed?

You are the technician on this run. Process every patient's sample across the microarray, then read which genes are switched up, down, or left unchanged.

The cohort

    Procedure

    1. Equilibration Buffer — coat every spot on the card.
    2. Dry the card in the incubator.
    3. Sample prep — add control cDNA to each well, mix, spot it.
    4. Dry again.
    5. Hybridisation Buffer — coat the sample spots.
    6. Dry, then reveal under UV and read the colours.
